# XPilot-AI Version Information

## Current Version

**Xpilot-AI 1.0** is based on XPilot Classic 4.5.5 and provides a complete AI development environment for creating bots that can play the classic XPilot multiplayer space combat game.

## Features

- **Complete AI API** - Full set of functions for bot development
- **Multiple Language Support** - C, Java, Python, and Racket support
- **Cross-Platform** - Works on Linux and Mac systems
- **X11 Graphics** - Traditional X11-based graphical interface
- **Custom Server** - Includes `switchBase` functionality for evolutionary AI training

## Platform Support

### Xpilot-AI 1.0 (Classic)
- ✅ **Linux** - Fully supported
- ✅ **Mac** - Fully supported  
- ⏳ **Windows** - Planned support coming soon

## Programming Languages

All platforms support the following programming languages for bot development:

- **C** - Native C programming with full API access
- **Java** - Object-oriented development with Java bindings
- **Python** - High-level scripting with Python wrapper
- **Racket** - Functional programming (previously PLT Scheme)
