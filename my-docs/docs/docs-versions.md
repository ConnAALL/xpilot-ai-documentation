# XPilot-AI Version Comparison

## Overview

Both versions include all of the same **bot functionality** and primarily only differ **graphically**.

**Xpilot-AI (Classic)** uses **X11** for its graphical environment, whereas **Xpilot-ng-AI (NG)** also includes an **SDL client**, although it is not yet supported.

## Platform Support

### Xpilot-AI (Classic)
- ✅ **Linux** - Fully supported
- ✅ **Mac** - Fully supported  
- ⏳ **Windows** - Planned support coming soon

### Xpilot-ng-AI (NG)
- ✅ **Linux** - Currently supported
- ❌ **Mac/Windows** - Not currently supported
- ⏳ **SDL client** - Planned for version 1.0
- ⏳ **Polygonal maps** - Planned for version 1.0
